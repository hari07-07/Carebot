# 🚗 IoT Based Smart Bot Car

An IoT-based smart robotic car controlled using a web interface and voice commands
with ESP8266 NodeMCU and safety sensors.

## Features
- Web & voice control
- ESP8266 WiFi control
- Ultrasonic obstacle detection
- PIR motion detection
- Gas leakage alert
- Mobile IP camera streaming

## Technologies Used
- ESP8266 NodeMCU
- Arduino IDE
- HTML, CSS, JavaScript
- IoT Sensors

## How to Run
1. Upload code to ESP8266
2. Connect to WiFi
3. Open ESP IP address in browser
4. Control the bot remotely
