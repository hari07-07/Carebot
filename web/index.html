🚗 IoT Based Smart Bot Car

Web & Voice Controlled Robotic Car using ESP8266

📌 Project Overview

This project implements an IoT-based smart robotic car that can be controlled remotely through a web interface and voice commands. The system uses an ESP8266 NodeMCU with integrated sensors for obstacle detection, motion sensing, and gas leakage monitoring.

⚙️ Technologies Used

  • ESP8266 NodeMCU
  • Arduino (Embedded C/C++)
  • HTML, CSS, JavaScript
  • Ultrasonic, PIR, Gas Sensors
  • Ngrok for global access

🚀 Features

  • Web-based robot control
  • Voice command automation
  • Obstacle avoidance
  • Motion & gas detection
  • Live video streaming (IP camera)
